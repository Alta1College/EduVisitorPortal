# Edu Visitor Portal v1.0.0

First release of Edu Visitor Portal: a visitor management platform for independent schools,
built on [VisitorPortal](https://github.com/P0etInc0de/VisitorPortal) by Jonathan Läpple and
VisitorPortal contributors (GPL-3.0-or-later).

## Highlights

### Sign-in
- **Reception kiosk** for iPads and tablets, including home-screen web apps: visitor types,
  configurable details and questions, a camera photo with adjustable zoom, and badge printing.
- **QR sign-in on the visitor's phone**, one code per site, with sign-out from the same phone.
- **Returning visitors** are recognised by email or phone. Saved details are shown masked and
  can only be reused or changed after an emailed 6-digit code.
- **Automatic sign-out** at a set time per site.

### Safety and compliance
- **WWCC and other credentials**: records per visitor, reception checks, expiry and re-check
  dates, search and CSV import.
- **Emergencies**: on-site register, roll calls with late arrivals, and SMS and email
  broadcasts (MessagePort) with delivery receipts. Broadcasts resume after a crash.
- **Immutable visitor log**: attended visits are view-only, visitor edits are audited, and
  the audit log is protected in the database.
- **Evidence retention** with legal holds.

### Hosts and staff
- **Microsoft Entra ID**: staff sign-in, host directory sync with one group per site.
- **Host alerts** by email, or by Microsoft Teams chat message from a bot.
- **MFA** for every password sign-in; single sign-on relies on the identity provider's own
  Conditional Access.

### Administration
- **Admin dashboard**: welcome panel, live tiles (on site now, today, compliance, safety),
  trend charts and system health.
- **Scheduled reports** (weekly, monthly, and after each roll call) by email as PDF with
  CSV, sent to recipient groups per site. CSV exports of visits and visitors.
- **Organisation settings** in the admin panel: branding and colours, sites, visitor types,
  questions, kiosk camera zoom, returning-visitor options, report recipients.
- **Badges** printed straight to network label printers.

## Platform

- Laravel 13, PHP 8.4, MariaDB 11.4, Filament 5, Livewire 4.
- English by default (German, French and Czech remain available); default timezone `UTC`.
  Set `APP_TIMEZONE` for your region before the first start.
- Docker deployment with optional Caddy for automatic HTTPS. Mail through SMTP or Microsoft
  Graph.
- CI: tests on MariaDB, Pint style check, licence header check, and a single sign-on
  end-to-end test against Keycloak.

## Installing

New installations: follow [deployment.md](../deployment.md) and
[configuration.md](../configuration.md). Generate `APP_KEY` once and keep it; it decrypts MFA
secrets and other encrypted data.

## Container Image

```text
ghcr.io/alta1college/eduvisitorportal:v1.0.0
```

For the production `.env`:

```env
VISITORPORTAL_IMAGE=ghcr.io/alta1college/eduvisitorportal:v1.0.0
```
